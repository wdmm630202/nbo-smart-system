# 南铂行业内容工作台操作合同

## 适用范围

本目录用于南铂摄影行业内容的选题、证据、文案、旁白、分镜、素材、字幕、渲染和质检。用户说“开始新一期”或“继续第 N 期”时，先读取对应 `project.json`，只从最后一个已验证阶段继续。

## 必须遵守

- 原始照片、视频和音频只读，不覆盖、不删除、不向原目录写中间文件。
- 研究使用低频、只读的公开访问；记录页面标题、URL、发布者、日期、访问日期、摘要和支持说法。
- 公开投诉只能证明“有人公开反映”，不能写成“已查实”。
- 不点名攻击具体同行，不虚构评价、案例、订单、投诉结果、行业比例或效果保证。
- 南铂营销说法只允许：`268拍摄2套`、`全部原片全送`、`不推销加精修`。
- 预约速度、交付时效、套餐其他内容未经用户明确确认不得进入宣传文案。
- 公开截图必须隐去姓名、头像、电话、订单号和其他可识别信息。
- 无关素材不得填充分镜；匹配不足时标记“缺素材”，或使用明确的中性文字动效。
- 生成的 MP4 不得冒充剪映或 ChatCut 可编辑工程。
- 不自动发布、不自动评论、不改变投放。

## 六阶段交付

1. `evidence`：选题、来源、说法与限定语。
2. `script`：口播、屏幕文案、平台文案。
3. `voice`：完整旁白、时长、试听记录和对齐。
4. `storyboard`：语义分镜、素材指纹、匹配理由和时间段。
5. `qa`：ffprobe、静音/黑帧、字幕安全区、隐私与事实门禁。
6. `export`：MP4、字幕、发布文案、证据报告、素材清单和质检报告。

所有阶段更新项目账本后再对外报告完成。未经用户亲自试听的声音保持 `userApproved: false`，可以标记为“推荐候选版”，不标记为用户已确认。
