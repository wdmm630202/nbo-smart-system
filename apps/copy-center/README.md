# 南铂文案中心

入口：<https://wdmm630202.github.io/nbo-smart-system/projects/copy-center/>

云端应用：<https://copy.nanbostudio.com/>

八个平台统一简体中文，目标地区默认国内，可选马来西亚、新加坡、台湾和海外华人。广告与八平台各地区版本保存到独立 Cloudflare D1；复制文案后在相应 App 发布。

## 日常使用

1. 输入访问码。访问码保存在负责人处，服务器通过 Cloudflare Secret 配置，不写入公开源码。
2. 新建广告并录入真实素材信息；或下载 CSV 模板整理后批量导入，每次最多 500 条。
3. 在工作台选择地区，补全八平台文案或生成当前平台。生成成功后保存为草稿，可继续修改。
4. 单独复制标题、正文或整段文案；发布后记录状态、日期与链接。
5. 修改前的最近 20 个版本可恢复；品牌与备份页支持 JSON 完整备份、CSV 文案导出和备份合并。大备份会自动分卷，导入时按 UTF-8 字节分批；网络失败可安全重试，已有广告不会被覆盖。
6. 素材编号创建后固定，可补充原文件名和封面链接。在“账号与套餐”添加真实官号、自媒体账号，选择主要受众时区；工作台显示当地与北京时间，自动按日期换算夏令时。默认午间、晚间时段仅为测试建议，可录入账号后台活跃时间替换。
7. 套餐主档支持生效、到期和停用。素材关联套餐后，套餐事实、共同政策或素材服务事实变化会提示复核；旧文案保持原样。确认复核只适用于当时的事实，到期及停用提醒不能用确认按钮消除。
8. 在工作台选择具体账号，发布后填写实际使用的文案、时间、作品或凭证链接并保存留底。留底为手动登记，只读保存，不代表已读取平台后台验证，也不会触发社交平台发布。恢复广告历史不会改动已建立的留底。
9. 完整 JSON 备份包含账号、套餐和留底。大备份先导入含广告的分卷，再导入留底分卷；通过永久素材编号重新关联留底。独立导出的留底 JSON 也可导入已有素材库。CSV 文案导出仍为当前草稿，不包含发布留底。

默认平台字数属于运营建议；实际硬性要求应在发布入口核对并写入平台规则。套餐与服务地点由用户填写。视频仅保存链接，AI 生成只接收文字资料，不读取链接中的媒体。

## 部署和恢复

源代码与总台在同一个 GitHub 仓库。数据库、登录会话和访问码不进入 GitHub。依次运行：

```sh
node tools/build-copy-center.mjs
npx wrangler deploy --config workers/copy-center/wrangler.jsonc
node tools/export-github-pages.mjs
```

首次安装通过 `workers/copy-center/schema.sql` 初始化专用 D1；现有库无需重新创建。绑定 `DB`、Workers AI `AI`，以 Secret `COPY_ACCESS_KEY` 配置访问码。变更访问码后如需立即撤销全部已登录设备，清空此应用专用库的 `sessions` 表。

本次账号发布留底升级需要在部署 Worker 之前，对现有专用 D1 执行最新 `schema.sql`（均为 `CREATE ... IF NOT EXISTS`，保留已有数据），新增 `publications` 表及索引。账号与套餐存入原配置 JSON；没有初始化虚构账号。备份不含登录会话和访问码。发布时间建议说明参考 [YouTube 账号活跃时间](https://support.google.com/youtube/answer/13616337?hl=zh-Hans)，默认具体时段属于南铂运营试验值。

`OpenCC-LICENSE` 对应 OpenCC 繁简转换字符词典；生成与保存时统一转换成简体中文。

验证：`npm run copy-center:test`，包含八平台生成结构、资料事实检查、登录、并发冲突、草稿保护、百条广告备份恢复、CSV 和总台接入测试。

工作台的平台标签下方提供对应官方电脑端入口，在新标签页打开，保留文案中心当前编辑。抖音、小红书、快手、TikTok 和 YouTube 连接上传入口；视频号连接官方视频号助手。Instagram、Facebook 连接官方网页版，登录后从创建或发帖进入。文案和本地素材不会通过链接自动传送，实际上传由用户在平台页面选择文件完成。
