# 简洁文案格式 Implementation Plan

**Goal:** 用户确认表单与生成结果都改成简洁版；默认一句自然短文案和五个男士写真相关话题。

**Architecture:** 保留现有广告、八平台版本、保存和备份结构。新建表单以一句话为主要输入，其余资料折叠选填；生成的标题和正文使用同一句短句，整段复制自动去重，CTA 留空。

**Tech Stack:** 原生 JavaScript、Cloudflare Worker、Node test runner。

## Constraints

- 不改写已有广告、手动文案、配置和发布留底。
- 默认生成标题/正文各不超过40字；正文单行一句话；五个不重复话题，围绕男士写真和真实拍摄城市。
- 不自动追加套餐、价格、到店介绍或私信营销；仅以现有真实资料作为背景。
- 旧稿仍可查看、保存、复制，不对手动编辑施加40字限制。
