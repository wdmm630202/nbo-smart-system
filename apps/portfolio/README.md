# 南铂真实客片网页

这是一个不需要安装软件、可直接发布的手机端静态网页。当前包含 12 个客片位置；照片不存在时会显示写有替换文件名的占位图。

## 替换照片

1. 在本项目中新建 `assets/photos` 文件夹。
2. 准备 12 张已获得展示授权的 JPG 客片，并同步导出同名 WebP 加速图。
3. 将照片依次命名为：

   `photo-01.jpg`、`photo-02.jpg` …… `photo-12.jpg`

   `photo-01.webp`、`photo-02.webp` …… `photo-12.webp`

4. 把照片放进 `assets/photos` 文件夹，刷新网页即可。

不需要修改代码。网页优先加载体积更小的 WebP；老设备不支持时自动回退到 JPG。建议照片使用竖版 3:4 比例，例如 `1080 × 1440`，JPG 每张控制在 700KB 以内，WebP 每张控制在 250KB 以内。

照片分类如下：

- `photo-01.jpg`～`photo-03.jpg`：商务西装
- `photo-04.jpg`～`photo-06.jpg`：日常松弛
- `photo-07.jpg`～`photo-09.jpg`：情绪光影
- `photo-10.jpg`～`photo-12.jpg`：个人形象

如果暂时不满 12 张，可以保留占位图测试，但正式发布前不要留下占位图。

## 本机预览

在这个文件夹启动一个本地网页服务：

```bash
python3 -m http.server 8765
```

然后用浏览器打开 `http://127.0.0.1:8765`。
