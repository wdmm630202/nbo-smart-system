# 南铂文案中心常用发布模板迭代

用户已确认采用现有发布文案架构，要求按不同广告长期生成。本次属于已有生成、复制流程的局部迭代。

- 默认架构：开头看点、素材介绍、实际城市及当前套餐、对应平台咨询、五个相关话题。标题与正文开头避免重复，正文按作品介绍和到店信息空行分段。
- 素材主题只有“作品展示”时，示范回退到本条广告名称；具体风格与画面仍由本条素材说明提供。无套餐时省略价格、交付承诺与价格咨询关键词。
- Facebook 使用 Messenger 私信，YouTube 使用评论留言；其他平台不得导向其他平台咨询。品牌设置中的普通咨询语气仍可采用，含旧价格或跨平台渠道时按当前素材适配。生成校验拒绝未确认的数字咨询关键词。
- YouTube 保留独立标题复制，底部“复制说明”只复制正文、咨询引导、话题；其他平台“复制整段”保留开头标题。CSV、历史和发布留底仍使用完整标题与文案。
- 八个平台统一简体中文；生成默认五个不重复话题，手动可增减。现有配色、发布入口和云端保存流程保留。
