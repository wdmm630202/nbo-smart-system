一次写入步骤

  1. 准备 NTAG215 卡片或贴纸
  2. iPhone 安装可信 NFC 写入工具
  3. 新建 URL / URI 记录并粘贴上面网址
  4. 写入后锁卡前，先用另一台手机碰卡测试
  5. 确认正常再贴到前台卡片
推荐 NTAG215。网址本身也能写入 NTAG213，但 215 留有更充足余量。不要把抖音私有协议直接写进 NFC，卡内只放 HTTPS 永久网址。
