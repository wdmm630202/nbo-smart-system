# 南铂写真复刻台

网页版与本地 Chrome 扩展：把参考图的灯光、色调、构图和环境迁移到本人写真，同时优先保护五官、年龄、体型和真实皮肤质感。

固定网页入口：<https://wdmm630202.github.io/nbo-smart-system/projects/photo-recreation/>

## 安装

最简单：双击 `打开南铂写真复刻台.command`，它会自动启动本机服务并在 Chrome 中打开工作台。

如果要安装成 Chrome 扩展：

1. 打开 Chrome，在地址栏输入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹。
5. 点击工具栏里的“南铂写真复刻台”，或在网页图片上右键选择“用作南铂参考效果”。

## 两种使用方式

- 无 API：上传参考图和本人写真后，点击“先生成复刻指令”，复制到支持多图编辑的生成工具。
- 有 API：在“设置”里选择 Google Gemini 或 OpenAI，填写自己的 API Key，再使用 AI 分析与生成。Gemini 默认用 `gemini-3.6-flash` 读图分析，用 `gemini-3.1-flash-image` 生成效果图。

图片默认只保存在当前页面内；只有主动点击 AI 分析或生成时，图片才会发送到所配置的 API。API Key 保存于 Chrome 本地存储。正式商用版应改为南铂自有服务器中转，不在浏览器里长期保存密钥。

## 保真边界

AI 图像编辑会重新生成部分画面，不能承诺百分之百保留原始皮肤像素。“保真优先”通过输入顺序和严格约束尽量保持五官、肤色、毛孔、痣与皮肤纹理；如果必须百分之百保留实拍皮肤，应使用人物分割和局部合成流程，只修改背景、色调及非人物区域。
