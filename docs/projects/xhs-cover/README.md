# 南铂真实客片封面

## 以后只做三步

1. 双击 `start.command` 打开工具。
2. 选择版式，替换成片和到店照，再修改两行封面字。
3. 点击“导出高清 PNG”。

导出的文件固定为 1080×1440 PNG，可直接作为小红书 3:4 封面使用。

## 照片位置

- 直接在封面预览上拖动，可以移动主图。
- 展开“照片位置微调”，可以调整主图和到店照的大小、左右及上下位置。
- 调乱后点击“恢复默认位置”即可。

## 两种版式

- **真实前后**：成片作为主图，右下角放大拍摄前素颜照；虚线框固定，照片四边自动溶入主图。
- **单张视觉**：只保留一张成片，适合光影、情绪和造型展示。

## 照片隐私

- 照片只在本机浏览器中读取和制作。
- 工具不上传照片，不使用云端接口，不保存客户照片到浏览器数据库。
- 刷新或关闭页面后，临时选择的照片不会被保留。
- 示例图来自本次提供的真实照片副本，源文件没有被移动或改写。

## 设计规则

- 两行主标题使用白色现代宋体，兼顾高级感和缩略图辨识度。
- 南铂黄 `#FEE800` 只用于标题下方的极细装饰线。
- 调整素颜照大小时，外层虚线的位置、大小、圆角和粗细不会变化。
- 每行建议控制在 4～7 个汉字。
- 封面两行避免写城市、人名、机构、品牌和夸张承诺。
- 人物照片只做等比裁切、缩放和移动，不拉伸、不换脸、不生成背景。
