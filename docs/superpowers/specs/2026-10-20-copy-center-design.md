# 南铂文案中心

## 已确认的目标

在 NBO 南铂智能系统登记一个真正可使用的云端文案中心。约 100 条广告，每条只登记一次素材信息，生成并独立保存抖音、小红书、快手、视频号、TikTok、Instagram、Facebook、YouTube 八个平台版本。所有生成内容统一简体中文；海外面向中文用户，地区可选马来西亚、新加坡、台湾、海外华人等。手机和电脑同步使用。

## 使用流程

新建或批量导入广告 → 填写真实主题、卖点、服务地点、套餐事实、素材链接 → 选择地区 → 生成八版草稿 → 逐平台修改、复制 → 标记待审核、待发布或已发布并记录链接。只重新生成选定平台时，其余人工版本保持原样。

## 界面与数据

- 广告库：编号、名称、主题、事实、素材链接、地区、创建与更新时间；支持搜索、地区和平台状态筛选、归档。
- 文案工作台：平台切换；标题、正文、话题、咨询引导、备注、发布日期、发布链接、状态独立编辑。提供单字段和整段复制。
- 平台规则：建议长度与话题数量、视频比例与时长备注、适用内容类型、来源和核对日期。未经核实的限制标为运营建议，不伪装为平台硬性限制；用户可修改规则。
- 发布看板：按平台和状态查看；切换状态保留文案。
- 导入导出：UTF-8 CSV 模板批量导入广告、JSON 完整备份恢复、CSV 文案导出。导入先预览统计，重复编号和错误行逐条提示；恢复执行合并，保留现有记录。
- 品牌设置：品牌、服务地点、事实与语气可编辑；套餐字段由用户确认后填写，不擅自增加承诺。

## 架构

公开 GitHub Pages 总台增加“南铂文案中心”卡片，永久入口为 `/nbo-smart-system/projects/copy-center/`，指向独立 Cloudflare Worker。Worker 同源提供响应式网页、受保护 API、Cloudflare D1 存储和 Workers AI 文案生成。运行和数据保存不依赖本机开机。采用现有 Cloudflare 账户，不创建新的第三方 AI 账户。

内部数据以独立 D1 保存；公开仓库仅保存程序、迁移与公开入口。访问码通过 Cloudflare Secret 配置；登录成功使用 HttpOnly Secure Cookie。写入检查来源，登录限流，记录编辑有版本号；并发冲突返回冲突提示并保留编辑内容。服务器端验证所有字段、平台枚举和大小，HTML 渲染转义外部输入。

八个平台输出均要求简体中文、真实事实、自然表达。生成时只发送用户录入的文字信息，视频仅保存用户填写的素材地址。AI 返回结构经过服务器校验；失败保留原文并给出可读错误，不将模板冒充 AI。请求设超时和输出长度限制。品牌、地区和规则变化不会直接覆盖人工文案。

## 验收

1. 未登录读取、修改广告被拒绝；登录退出可用。
2. 新建、修改、跨会话读取、归档、批量导入与备份合并可用。
3. 同一广告有八个平台独立版本，全部使用简体中文；定向重新生成不覆盖其余版本。
4. 两个客户端并发保存时提示冲突；网络失败不显示保存成功。
5. 手机窄屏和桌面完成新建、生成、修改、复制、标记发布，页面不横向溢出。
6. 总台源码和发布页均登记入口，正式域名和入口可打开，实际 AI 请求成功。
