# 南铂男士写真主题分类

## 三层结构

1. 场景：内景 / 外景
2. 主题：客户能一眼产生画面的短名
3. 气质：商务 / 松弛 / 情绪 / 创意

主题名优先使用 4 个字，最长不超过 6 个字。地点、服装、节日、人设和交付项目不再混在同一层。

## 内景主题

- 商务总裁
- 杂志肖像
- 光影情绪
- 复古港风
- 居家韩系
- 花艺少年
- 拳击荷尔蒙
- 运动型格
- 赛博朋克
- 国风武侠
- 生日节日
- 创意概念
- 宠物合拍

## 外景主题

- 都市街拍
- 日常漫游
- 机车型格
- 城市夜景
- 森系文艺
- 校园少年
- 正装外景
- 国风外景
- 旅行叙事
- 运动纪实

## 旧名称整理规则

- `职业形象照 / 霸道总裁 / 西装红色杂志` 分别归入商务总裁或杂志肖像。
- `情绪氛围 / 暗系情绪 / 情绪隧道` 按场景归入光影情绪或城市夜景。
- `网球运动 / 腹肌健身 / 运动风` 归入拳击荷尔蒙、运动型格或运动纪实。
- `新年 / 圣诞 / 雪花 / 秋冬` 统一收入生日节日，用上线时间和说明区分季节。
- `拼图展示 / 视频 / 模卡 / 资料` 是交付形式，不再当作拍摄主题。
- 具体地点如琶醍、天台、海边、香港等放入主题描述或拍摄地标签，不占用主题名。

## 新照片入库

先判断是内景还是外景，再选一个主题，最后选一个气质。一组双图必须保持同一主题，不得拆分。
