# 国内底稿加工八平台文案

**Goal:** 一次录入国内文案，保留视频主题，生成各平台简洁文案；海外四平台面向马来西亚、新加坡、台湾，邀请来真实服务城市拍摄。

**Architecture:** 复用现有广告、版本、生成接口，不新增数据表。国内参考优先抖音，其次小红书、快手、视频号；先用“国内”地区，缺失再用当前地区，最后回退其他地区已有国内平台稿。全平台缺稿时先生成抖音，再并发补其余平台。单独海外生成无国内稿时使用素材信息。补全不覆盖已有版本。

**Constraints:** 简体中文；标题贴合视频；正文单行一句且40字内；海外标题与正文独立，正文自然带拍摄邀请；海外默认两个业务话题加马来西亚、新加坡、台湾，共5个；国内原规则保留，快手4个、其他5个、视频号短标题6–16字；不编造海外门店、套餐、经历；现有手动文案与发布记录不变。

## Review focus

Review fixes: 切换地区底稿选择统一；国内稿只补充视觉描述来源，价格与服务仍仅以当前事实为准；海外平台无论区域都校验人民币；保留线上已更新的20:30时段默认值。
