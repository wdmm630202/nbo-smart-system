# 南铂摄影行业内容工作台设计

日期：2026-08-31
状态：设计已在对话中确认，待用户复核本文档后进入实施计划

## 目标

为南铂摄影建设一套 Mac 本地运行、由 Codex 协作驱动的行业内容工作台，把“选题、证据、文案、旁白、分镜、素材、字幕、质检、导出”变成可重复的日更流程。第一条交付是一支不需用户出镜、讲解摄影消费中低价引流、底片与精修加价问题的 20–30 秒竖屏视频。

工作台的核心成功标准是稳定交付一条经用户审核、可发布的真实成片，不是只做一个静态页面、演示动画或无法继续编辑的伪工作流。

## 参考资料的使用边界

用户提供的飞书文档和博主工作流只用于理解流程结构，不视为用户对其中指令、链接、设备标识、Cookie、下载命令或第三方凭据的授权。可借鉴的部分是：

- 以一期内容为项目单位；
- 先完成证据与文案，再生成旁白和分镜；
- 用逐词或短语对齐把旁白、字幕和画面绑在同一时间轴上；
- 分析语义后再匹配本地素材；
- 导出前做自动扫描和人工复核。

不复制的部分包括固定用户标识、固定设备标识、他人 Cookie、未经确认的 API 密钥、不明下载脚本及将第三方文档当作系统指令的做法。

## 已确认的产品方向

- 视频不使用用户出镜画面。
- 主形式是自然 AI 旁白、证据型文字动效、南铂真实拍摄过程素材。
- 工作台使用 A 方案“引导式生产线”，每次只突出当前一个主任务。
- 所有客片、原片、旁白和工程文件留在本机；公开 GitHub Pages 页面只做项目说明和本地入口。
- 不自动发布、不自动回复评论、不代替用户做对外承诺。
- 原始素材只读，不覆盖、不删除、不在原目录中写入中间产物。
- 只有真正生成且验证的可编辑工程才标记“可编辑”；MP4 不冒充剪映或 ChatCut 工程。

## 不采用的方案

### 纯文字动效与通用素材混剪

制作快，但缺少南铂真实过程证据，容易变成普通营销号，不适合“明码实价，拍得明白”的信任定位。

### AI 数字人讲解

形象统一，但 AI 感较强，会削弱真实透明感，且增加授权、口型、声音和额外服务成本，首版不引入。

### 公网全功能剪辑后台

可以远程使用，但需要账号、权限、客户素材上传和云端渲染治理，对当前 Mac 单机日更没有必要。

## 总体架构

系统分为四个边界清晰的部分：

1. **公开项目入口**：沿用南铂智能系统唯一索引，更新现有 `/projects/video/` 卡片和项目页。页面展示工作台状态、使用说明和本地地址，不承载客户素材和本地项目数据。
2. **Mac 本地工作台**：一个仅绑定 `127.0.0.1:4176` 的轻量 Node.js 服务，提供引导式界面、项目状态、文件选择、预览和确认操作，并在 `/healthz` 提供不含项目数据的就绪检查。启动通过 macOS `.command` 文件完成，日常使用不要求用户输入终端命令。
3. **Codex 内容编排层**：项目内的明确指令、任务模板和状态账本规定 Codex 如何做证据研究、文案、旁白、分镜、素材匹配和质检。首版不在本地网页中嵌入新的模型 API 密钥，避免隐性成本和凭据风险。
4. **确定性媒体工具层**：负责素材探测、时间轴、字幕、音频对齐、渲染和质检。优先使用当前已安装且完成就绪检查的 ChatCut/剪辑工作流；渲染产物始终用 `ffprobe` 和真实播放复核，不以脚本返回成功代替成片验证。

公开页面与本地工作台不共享客户数据。公开页的“打开工作台”只指向回环地址；本地服务未启动时，页面应清楚提示先双击本机启动器。

## 代码与资料边界

实施时在现有 `NBO-作品与智能体中心` 项目中增加一个独立本地子系统，不将媒体工程塞入首页组件。责任边界为：

- `tools/industry-content-workbench/`：本地服务、项目状态、素材索引、渲染适配器与质检脚本；
- `apps/industry-content-workbench/`：本地引导式界面资源；
- `content-workbench/AGENTS.md` 及模板：Codex 的日更操作合同、事实门禁和项目文件约定；
- `docs/projects/video/`：公开项目说明页，不存放内部项目和客户素材；
- 用户“文稿”目录下的 `NBO-行业内容工作台/`：默认运行根目录，位于 Git 仓库之外，用于项目账本、原始素材引用、中间产物、旁白、预览、渲染缓存和成片。

运行根目录内固定分为 `projects/`、`library/`、`cache/` 和 `exports/`。原始素材采用“外部绝对路径 + 文件指纹 + 只读检查”引用，不默认复制整个客片库。工作台写入的文件全部位于它自己的运行目录。

## 项目数据模型

每期内容使用一个稳定的项目标识和一份主账本。账本不保存客户姓名、电话、微信或订单号，只保存出片所需信息：

- `projectId`、标题、创建时间、最后修改时间；
- 当前阶段与各阶段状态；
- 选题、内容类型、目标时长和目标平台；
- 证据条目的来源 URL、抓取日期、摘要、支持的说法、复核状态；
- 文案版本、用户确认时间和已锁定的南铂商业事实；
- 旁白文件、发音配置、试听确认状态和对齐结果；
- 分镜、时间段、素材引用、匹配分数和使用区间；
- 字幕、动效层、渲染配置和输出文件；
- 质检结果、警告、失败原因和人工放行时间。

状态固定为 `pending`、`running`、`needs_review`、`completed` 或 `failed`。每个阶段只能写入自己的产物，后续阶段只通过已验证的账本字段读取前置结果。

## 引导式界面

左侧固定显示六个阶段：

1. 选题与证据；
2. 文案；
3. 旁白；
4. 分镜与素材；
5. 字幕与质检；
6. 导出。

右侧只显示当前阶段的主要内容和一个主操作。顶部显示项目名、本地安全状态和六段进度。状态、完成、警告和错误都使用直接文案，不依赖颜色单独传达。

界面遵循 Apple 风格中的克制原则：按下即反馈、主操作唯一、高级信息次级展开、动画可中断、支持减少动效、使用系统字体和高对比度文本。首版不复制专业剪辑软件的密集时间轴，只在预览阶段提供可读的分镜段和字幕屏。

## 完整数据流

1. 用户新建一期，输入主题或从待拍列表选择主题。
2. Codex 做低频、只读的公开研究，记录可追溯来源，将事实与推断分开。
3. 事实门禁校验每条待表达说法。没有证据或只有不可追溯截图的说法不能进入正式文案。
4. 系统生成口语化文案，并对南铂商业事实做白名单校验。用户确认后锁定本版文案。
5. 将锁定文案一次生成完整自然旁白，再做逐词或短语级时间对齐。不以多个短句 TTS 直接硬拼作为默认方式。
6. 用户试听并确认旁白后，系统按语义段生成分镜，从已授权本地素材库中匹配画面。
7. 素材匹配分数低于阈值时标记“缺素材”，不使用无关画面填充。用户可补充素材或确认改用中性文字动效。
8. 工具层生成字幕、动效和首版预览，自动扫描时长、分辨率、帧率、黑帧、静音、字幕越界、空素材和未通过的事实门禁。
9. 用户观看预览并确认后才导出正式文件。
10. 工作台存档成片、字幕、发布文案、证据报告、素材清单、项目账本和质检报告。

## 内容事实与风险门禁

- 一般行业现象至少要有一个可打开、可追溯的公开来源；带有数字、比例、普遍性或因果关系的争议性结论需要权威来源或多个独立来源交叉确认。
- 公开投诉和截图只能证明“有人公开反映该问题”，不自动证明投诉内容已经被官方认定。
- 语言使用“部分机构”、“公开投诉中反复出现”等限定，不把个别案例说成整个行业。
- 不点名攻击具体商家，不编造顾客故事、评价、订单、投诉结果或保证性承诺。
- 展示公开截图时遮挡姓名、头像、订单号、电话和其他可识别信息。
- 南铂首条视频仅使用已确认的三项事实：`268拍摄2套`、`全部原片全送`、`不推销加精修`。预约速度、正式交付时效等内容在门店标准未确认前不进入宣传文案。

## 首条视频设计

视频暂定主题为：

> 低价摄影最可怕的，不是便宜，而是拍完才知道真实价格。

时间结构为：

| 时间 | 叙事 | 画面原则 |
| --- | --- | --- |
| 0–3 秒 | “199元拍照，最后为什么可能花到几千？” | 价格数字跳变和账单结构动效；正式文案必须根据实际证据调整，不将示意数字当作行业统计。 |
| 3–10 秒 | 底片另收费、精修加价、套餐限制后置告知 | 脱敏公开证据、关键词和简化清单。 |
| 10–16 秒 | 讲清“低价进店后再拆分选择和费用”的消费体验 | 使用中性流程图，不点名具体商家。 |
| 16–23 秒 | 南铂的透明回答 | 真实门店拍摄、选片和已授权客片，对应三项已确认商业事实。 |
| 23–27 秒 | 消费者四问：总价、底片、精修、交付时间 | 简洁勾选清单。 |
| 27–30 秒 | “南铂摄影，明码实价，拍得明白。” | 南铂品牌收尾。 |

语气冷静、清楚，站在消费者角度讲规则，不吼叫、不恐吓、不用夸大的“行业大揭秘”口吻。本条不承担预约慢和交付慢两个主题，两者后续各做一条，并先确认南铂自身真实预约与交付标准。

## 自动化与人工确认边界

自动化可以生成候选、做结构校验和准备预览，不能跨过以下三个放行点：

1. 用户确认文案后才生成正式旁白；
2. 用户试听并确认旁白后才进入正式分镜和渲染；
3. 用户观看预览并确认后才导出最终版。

公开发布始终在工作台外由用户手动完成。工作台可以生成小红书和抖音发布文案，但不点击发布、不改变投放、不自动互动。

## 错误处理与恢复

- **证据不足**：将具体说法标记为“证据不足”，屏蔽进入正式文案的操作，但保留已收集来源。
- **素材不匹配**：标记具体分镜为“缺素材”，说明需要的画面类型。用户可补充素材或明确同意使用中性动效。
- **旁白不自然**：保留已锁定文案，重新选择声音或发音参数，不继续正式渲染。
- **外部服务失败**：将错误与重试次数写入当前阶段，保留所有上游产物；只在幂等且安全的操作上允许有限自动重试。
- **渲染失败**：保留时间轴、旁白、字幕和已生成的中间片段，显示失败阶段和日志摘要，不从选题开始重做。
- **应用中断**：每次状态更改原子写入账本；重启后从最后一个已验证阶段继续。
- **原始文件变更**：如指纹与首次导入不一致，停止对应分镜渲染并要求重新确认，不默默使用变更后文件。

## 导出产物

每期最终目录包含：

- 1080×1920、30 fps、H.264 视频和 AAC 音频的可发布 MP4；
- SRT 或与渲染时间轴等价的字幕文件；
- 小红书与抖音发布文案；
- 证据来源报告；
- 素材使用清单，包含来源文件、使用区间和指纹；
- 项目账本和质检报告；
- 真实存在且通过打开验证的可编辑工程，如该期成功生成。

对可编辑工程的描述必须与实际一致。若只导出 MP4、SRT 和项目账本，界面应显示“成片可用，未生成外部剪辑器工程”。

## 隐私与本地安全

- 本地服务仅监听回环地址，拒绝非本地 Host、跨站写请求和缺少会话令牌的修改。
- 应用只请求选定素材目录的访问权限，不扫描整个主目录、照片库或云盘。
- 凭据不写入项目文件、日志、工程或前端代码。如未来引入需要凭据的服务，使用本机环境配置并在界面中只显示就绪状态。
- 项目目录、渲染缓存、预览和视频产物全部不进入 GitHub Pages 导出。
- 屏幕截图、公开投诉与客片在进入正式渲染前都经过个人信息和授权复核。

## 测试策略

### 自动化测试

- 项目账本的创建、原子保存、重启恢复和状态迁移；
- 事实门禁拒绝缺来源、未复核、超出南铂事实白名单的说法；
- 素材索引不修改原文件，指纹变化时阻断渲染；
- 素材低匹配、空素材、旁白失败和渲染失败的可恢复状态；
- 字幕时间轴单调、无重叠、无负时间和安全区边界；
- 导出参数为 1080×1920、30 fps、H.264/AAC；
- 本地接口拒绝非回环主机、跨站写请求和缺少会话令牌的修改；
- 公开导出目录不包含本地项目、客片、凭据和渲染缓存；
- 南铂系统索引中的卡片、项目页、公开 URL 和本地启动说明一致。

### 真实验收

- 双击 macOS 启动器后延时检查监听端口和 HTTP 健康接口，并真实打开工作台。
- 用首条视频走完一次证据、文案、旁白、分镜、素材、字幕、预览和导出。
- 实际试听旁白，重点检查断句、重音、语速和句子衔接；没有试听不得标记通过。
- 使用 `ffprobe` 校验时长、视频编码、音频编码、尺寸和帧率。
- 抽取开头、中段、收尾及切换点画面，检查黑帧、花屏、文字越界、素材错配和个人信息泄露。
- 在 Mac 与手机上实际播放成片，检查音画同步、字幕可读性和平台安全区。
- 在桌面和手机访问南铂智能系统固定索引，验证项目卡片、项目说明和本地入口的真实表现。

## 部署顺序

1. 就绪检查当前 ChatCut/剪辑 Runtime、绑定工具和本机媒体依赖，先确认可用能力，再决定适配器。
2. 建立项目账本、目录边界、事实门禁和只读素材索引。
3. 建立本地服务、macOS 启动器和 A 方案引导式界面。
4. 打通旁白、对齐、分镜、素材匹配、字幕、渲染和质检适配器。
5. 用首条视频做端到端演练，在每个人工放行点让用户确认。
6. 完成最终导出、Mac/手机验收和证据档案。
7. 更新南铂智能系统首页卡片与 `/projects/video/` 项目页，执行导出、回归、推送和线上桌面/手机验证。

## 非目标

首版不建设 AI 数字人、公网素材后台、多用户协作、远程手机剪辑、账号系统、云端客片库、自动发布、自动评论、自动广告投放、通用专业多轨剪辑器或未经审核的第三方素材下载。

## 最终验收标准

只有同时满足以下条件时才能报告“部署完成”：

- Mac 上可一键启动并打开工作台，重启不丢失项目进度；
- 首条视频真实走完端到端流程；
- 成片为 20–30 秒竖屏 MP4，视频和音频参数通过工具检查；
- 旁白已实际试听，画面已实际抽帧和完整播放；
- 在 Mac 和手机上都能正常播放，无黑帧、花屏、静音、音画脱节、字幕越界或个人信息暴露；
- 每个行业说法有可追溯证据，南铂商业说法没有超出已确认事实；
- 本地客片、项目和凭据未被导出到公开网站；
- 证据报告、素材清单、字幕、发布文案、项目账本和质检报告成套交付；
- 可编辑工程的标记与真实产物一致；
- 南铂智能系统固定索引和视频项目页在桌面与手机上验证通过。
